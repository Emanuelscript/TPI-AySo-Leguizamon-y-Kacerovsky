## 📌 Descripción del Proyecto
Este repositorio contiene la documentación y los recursos del Trabajo Práctico Integrador. El proyecto consiste en el despliegue de un laboratorio virtual seguro utilizando **VirtualBox** y **Ubuntu**, sobre el cual se configuraron servicios de red, políticas de ciberseguridad y una herramienta desarrollada en **Python** para el análisis automatizado de redes locales.

---

## 🛠️ Tecnologías y Herramientas Implementadas
* **Virtualización:** Oracle VM VirtualBox (Modo Adaptador Puente y gestión de Snapshots).
* **Sistema Operativo:** Ubuntu 26.04.1 LTS.
* **Seguridad y Redes:** OpenSSH, Servidor Web Apache (HTTPS), UFW (Firewall) y Fail2Ban (prevención de accesos no autorizados).
* **Automatización:** Programación de tareas mediante Cron.
* **Desarrollo:** Script en Python para escaneo de IPs, detección de hosts activos y verificación de puertos mediante *sockets* e *hilos*.
